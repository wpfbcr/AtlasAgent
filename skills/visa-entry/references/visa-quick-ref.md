# 签证官方查询入口

按用户的护照签发地区、居住地、目的地、过境地和出行日期查询。各国停留天数、费用和电子授权要求会变化，此文件提供查询入口；最终结论引用具体政策页面及本次查询日期。

## 已核验案例

中国大陆普通护照一般赴日旅游须提前办理签证；停留期限按签证及入境许可。来源：[日本外务省中国公民签证说明](https://www.mofa.go.jp/j_info/visit/visa/topics/china.html)，核验日期 2026-10-10。中国大陆普通护照、香港/澳门特区护照和台湾地区证件应分别核查。

## 查询路由

| 目的地/业务 | 官方入口 | 核查内容 |
|---|---|---|
| 日本 | https://www.mofa.go.jp/j_info/visit/visa/ | 护照类别、旅游签证、适用居住地 |
| 新加坡 | https://www.ica.gov.sg/enter-transit-depart | 入境、签证及申报 |
| 泰国 | https://www.thaievisa.go.th/ | 签证及适用免签条件 |
| 马来西亚 | https://www.imi.gov.my/ | 签证、入境及申报 |
| 美国 | https://travel.state.gov/ | 签证、免签计划及过境条件 |
| 美国 ESTA | https://esta.cbp.dhs.gov/ | 资格、当前费用及有效期 |
| 加拿大 | https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada.html | 签证/eTA 的个人资格 |
| 英国 | https://www.gov.uk/check-uk-visa | 签证/ETA 及适用条件 |
| 申根 | https://home-affairs.ec.europa.eu/policies/schengen/visa-policy_en | 签证政策，再查具体使领馆 |
| 澳大利亚 | https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-finder | 按护照选择 ETA/eVisitor/访客签证 |
| 新西兰 | https://www.immigration.govt.nz/ | 签证/NZeTA 及适用条件 |
| 中国 | https://cs.mfa.gov.cn/ | 领事、护照及出入境查询 |

表内入口仅用于定位官方政策，不代表已逐项核验当前具体政策。查询入口不能替代支持结论的具体页面。费用以官方申请页面为准，不使用历史固定金额。

## 完成标准

输出前确认签证类型、允许停留期限、护照有效期、空白页要求、过境条件及政策查询日期；未取得足够资料时标记待确认。国内行程的签证分析标为不适用。
